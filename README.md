# Stategraph Package Repository

This repository hosts APT and YUM package repositories for Stategraph, distributed via GitHub Pages.

## Installation Instructions

### Ubuntu/Debian (APT)

```bash
# Download and install the GPG key
curl -fsSL https://stategraph.github.io/releases/apt/KEY.gpg | sudo gpg --dearmor -o /usr/share/keyrings/stategraph.gpg

# Add the Stategraph repository
echo "deb [signed-by=/usr/share/keyrings/stategraph.gpg] https://stategraph.github.io/releases/apt stable main" | sudo tee /etc/apt/sources.list.d/stategraph.list

# Update and install
sudo apt update
sudo apt install stategraph
```

### Fedora/RHEL/Rocky/Alma (YUM/DNF)

```bash
# Add the Stategraph repository
sudo tee /etc/yum.repos.d/stategraph.repo <<'REPOEOF'
[stategraph]
name=Stategraph Repository
baseurl=https://stategraph.github.io/releases/yum
enabled=1
gpgcheck=1
gpgkey=https://stategraph.github.io/releases/yum/RPM-GPG-KEY-stategraph
REPOEOF

# Install
sudo dnf install stategraph
```

## Automated Updates

This repository is automatically updated by GitHub Actions when new Stategraph releases are published.

**Workflow:**
1. Release tagged in [stategraph/stategraph-code](https://github.com/stategraph/stategraph-code)
2. Packages built (.deb and .rpm for amd64 and arm64)
3. Packages uploaded to GitHub Releases
4. Repository metadata updated on gh-pages branch
5. GitHub Pages deploys updates automatically

## Manual Verification

### Verify APT repository

```bash
# Download and verify Release file
curl -fsSL https://stategraph.github.io/releases/apt/dists/stable/InRelease | gpg --verify

# List available packages
curl -fsSL https://stategraph.github.io/releases/apt/dists/stable/main/binary-amd64/Packages.gz | gunzip
```

### Verify YUM repository

```bash
# Download and verify repository metadata
curl -fsSL https://stategraph.github.io/releases/yum/repodata/repomd.xml
curl -fsSL https://stategraph.github.io/releases/yum/repodata/repomd.xml.asc | gpg --verify

# Import GPG key manually
curl -fsSL https://stategraph.github.io/releases/yum/RPM-GPG-KEY-stategraph | sudo rpm --import -
```
